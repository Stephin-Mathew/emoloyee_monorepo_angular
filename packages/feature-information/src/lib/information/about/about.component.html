Employee Management · Version 1.0

What is this application?

Employee Management is a simple tool for keeping track of the people in your organisation. Everyone can look up employee information, while only the users the admin has approved can make changes.

It is designed to be easy to use: a table for quick searching and editing, a list for reading details, and one place where the admin controls who is allowed to change records.

User roles

Admin can add, edit and delete employees and decides what every other user is allowed to do.

Normal users can view employees. Add, edit and delete are available only when the admin turns them on for that user.

Action Admin Normal user
View, search and sort employees Yes Yes
Add an employee Yes Only if allowed
Edit an employee Yes Only if allowed
Delete an employee Yes Only if allowed
Manage other users' access Yes No
